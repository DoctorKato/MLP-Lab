01 / Single layer

一条直线，止步于 XOR

单层感知器把输入加权求和，再按阈值输出 0 或 1。它的边界永远是一条直线；XOR 的两类点在对角线上交错，直线最多只能判对三个。

单层感知器 · 拖动参数 3 / 4

判定式 z = w₁x₁ + w₂x₂ + b；z ≥ 0 输出 1。上限是 3 / 4。

判定 z = w₁x₁ + w₂x₂ + b y = 1  if  z ≥ 0

权重决定直线的方向，偏置让它平移。无论怎么调，这条直线都无法同时把 (0,0)、(1,1) 放进一侧，(0,1)、(1,0) 放进另一侧。

  1. 1943麦卡洛克与皮茨提出阈值单元，用加权求和与阈值模拟“与”“或”。
  2. 1957–58罗森布拉特提出感知器，权重可以按带标签样本调整。
  3. 1969闵斯基与帕普特分析单层感知器的局限，指出 XOR 这类问题需要中间层。

02 / Hidden space

隐藏层换了一套坐标

两个隐藏单元各自盯住一个角：h₁ 对 (1,0) 响应，h₂ 对 (0,1) 响应。同一个输入被映射到 (h₁, h₂) 之后，两个对角点几乎落到原点，输出层一条直线就能分开。

04 / Implementation

五件事，一次反向传播

课程把实现拆成五步。下面的 JavaScript 不依赖框架，梯度由链式法则手写；每一轮与 PyTorch 的 loss.backward() 和 optimizer.step() 对应。

  1. 01

    张量

    X 为 4×2，Y 为 4×1。四个 XOR 样本整批训练，一次更新用完全部样本。

  2. 02

    模型

    h = σ(xW + b)，z = h·v + b₀。2 个隐藏单元，Sigmoid 激活。

  3. 03

    损失

    二元交叉熵直接作用在原始分数 z 上：max(z,0) − zy + log(1+e−|z|)。

  4. 04

    求梯度

    δ = (p − y)/4 逐层回传，得到 ∂L/∂W、∂L/∂b、∂L/∂v、∂L/∂b₀ 共 9 个分量。

  5. 05

    更新

    Adam：θ ← θ − lr·m̂ /(√v̂ + ε)，β₁=0.9，β₂=0.999。

PyTorch · 与课程同一套设置2–2–1
import torch, torch.nn.functional as F
torch.set_default_dtype(torch.float64)

x = torch.tensor([[0.,0.],[0.,1.],[1.,0.],[1.,1.]])
y = torch.tensor([[0.],[1.],[1.],[0.]])

W  = torch.nn.Parameter(torch.tensor([[2.,-2.],[-2.,2.]]))
bh = torch.nn.Parameter(torch.tensor([-1.,-1.]))
v  = torch.nn.Parameter(torch.tensor([[3.],[3.]]))
b0 = torch.nn.Parameter(torch.tensor([-2.5]))
opt = torch.optim.Adam([W, bh, v, b0], lr=0.03)

for epoch in range(300):
    opt.zero_grad(set_to_none=True)
    h = torch.sigmoid(x @ W + bh)   # 2 个隐藏值
    z = h @ v + b0                  # 原始输出分数
    loss = F.binary_cross_entropy_with_logits(z, y)
    loss.backward()                 # 框架自动求导
    opt.step()                      # Adam 更新
JavaScript · 本页实际运行手写梯度
function forward(p, x) {
  const h0 = sig(x[0]*p.w00 + x[1]*p.w10 + p.bh0);
  const h1 = sig(x[0]*p.w01 + x[1]*p.w11 + p.bh1);
  const z  = h0*p.v0 + h1*p.v1 + p.bo;
  return { h0, h1, z, p: sig(z) };
}

function backward(model) {
  const g = { w00:0, w01:0, w10:0, w11:0,
              bh0:0, bh1:0, v0:0, v1:0, bo:0 };
  for (let i = 0; i < 4; i++) {
    const { h0, h1, p } = forward(model.p, X[i]);
    const d = (p - Y[i]) / 4;            // dL/dz
    g.v0 += h0*d; g.v1 += h1*d; g.bo += d;
    const d0 = d * model.p.v0 * h0 * (1-h0);
    const d1 = d * model.p.v1 * h1 * (1-h1);
    g.w00 += X[i][0]*d0; g.bh0 += d0; g.w10 += X[i][1]*d0;
    g.w01 += X[i][0]*d1; g.bh1 += d1; g.w11 += X[i][1]*d1;
  }
  return g;
}

05 / Brief

作业说明

页面本身就是答案：实现、训练、可视化都在浏览器里完成，不依赖外部图片或模型文件。

本次交付

  • 手写实现：2–2–1 前向传播、BCE 损失与反向传播，不使用自动微分。
  • 三种视图：决策曲面、隐藏层坐标、损失曲线；9 个参数与本轮梯度同步刷新。
  • 可复现：固定初始化、整批梯度、Adam 0.03、300 轮；暂停、单步、重置都可操作。

三个探究

  1. 学习率对比分别用 0.005、0.03、0.2 跑满 300 轮，记录最终损失与“首次 4 / 4”的轮次。
  2. 对称性把 app.js 初始化中的 v₁、v₂ 同时改为 −3 再训练，观察结果并解释初始化为什么会改变收敛路径。
  3. 手推梯度写出 ∂L/∂W 的链式法则，与本页参数表中的梯度条逐项对照。
